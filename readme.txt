PRIYOJIT AGENCY WEBSITE
=======================

Files:
- index.html
- style.css
- script.js

RUN LOCALLY IN VS CODE
1. Extract the ZIP.
2. Open the extracted folder in Visual Studio Code.
3. Install the "Live Server" extension.
4. Right-click index.html and choose "Open with Live Server".

PUBLISH WITHOUT BUYING A DOMAIN
1. Create your own account at https://app.netlify.com/drop
2. Upload the extracted project folder (the folder containing index.html).
3. Netlify will provide a free address ending in netlify.app.
4. You can later connect a custom .in or .com domain.
